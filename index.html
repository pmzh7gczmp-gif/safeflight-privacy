안전비행 개인정보처리방침

시행일: 2026-10-29

"안전비행"(이하 "앱")은 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리합니다.

1. 수집하는 정보

항목수집 방법목적보관
위치정보(위도·경도)기기의 위치 서비스현재 위치가 드론 비행금지·제한구역에 해당하는지 판정, 해당 지역 기상정보 조회저장하지 않음 (기기 메모리에서만 사용)
  • 앱은 회원가입이 없으며 계정, 이름, 이메일, 연락처, 기기식별자를 수집하지 않습니다.
  • 검색창에 입력한 내용은 좌표 조회 목적으로만 쓰이며 기기에도 서버에도 남지 않습니다.
  • 위치정보는 앱 실행 중에만 사용하며, 앱을 종료하면 사라집니다.
  • 위치 이력을 기록하거나 서버에 전송·저장하지 않습니다.
  • 광고 식별자를 수집하지 않으며 광고를 게재하지 않습니다.
  • 기기에는 공역 자료와 'NOTAM 표시 켬/끔' 설정만 저장되며, 여기에는 개인정보가 포함되지 않습니다.

2. 위치정보의 제3자 전송

비행 가능 여부 판정은 기기에 있는 공역 데이터로 기기 내에서 처리하므로, 판정을 위해 위치가 외부로 나가지 않습니다.

다만 아래 기능을 사용할 때에 한해 위치가 해당 서비스로 전달됩니다.

서비스전달되는 정보시점
카카오 지도 (카카오)지도에 표시되는 영역 좌표지도를 보는 동안
카카오 지도 (카카오)이용자가 입력한 검색어(주소 또는 장소명)이용자가 검색창에 두 글자 이상 입력한 경우에 한함
기상청 API 허브위치를 변환한 5km 격자 번호(정확한 좌표가 아님)이용자가 "날씨" 버튼을 누른 경우에 한함
Open-Meteo (open-meteo.com, 해외 서비스)날씨를 볼 지점의 위도·경도"날씨" 버튼을 눌렀는데 기상청 응답을 받지 못한 경우에 한해, 예비로 조회

검색어는 좌표를 찾기 위해 카카오로 전달될 뿐이며, 앱이 검색 기록을 저장하거나 이용자의 현재 위치와 함께 보내지 않습니다.

각 서비스의 개인정보 처리는 해당 사업자의 방침을 따릅니다.

3. 공역 데이터 서버

앱은 실행할 때 공역 데이터 서버(airspace.drone119korea.com, Cloudflare 기반)에서 최신 공역 자료(실시간 NOTAM 포함)를 내려받습니다.

  • 이 요청에는 위치·검색어·기기식별자 등 개인정보가 포함되지 않으며, 모든 이용자가 같은 자료를 받습니다.
  • 일반적인 인터넷 통신과 마찬가지로, 서버 운영 과정에서 접속 IP·접속 시각 등 통신 기록이 Cloudflare에 일시적으로 남을 수 있습니다. 개발자는 이를 이용자를 식별하는 데 쓰지 않습니다.
  • 내려받은 공역 자료는 기기에 저장되며, 서버에 연결할 수 없을 때는 기기에 있는 자료로 동작합니다.
